# sportShop — Project Documentation

این پوشه مرجع مستندات پروژه است. مخزن GitHub منبع حقیقت پروژه محسوب می‌شود؛ نه حافظه گفت‌وگوها.

## ترتیب مطالعه برای هر گفت‌وگوی جدید
1. `AI_WORKFLOW.md`
2. `SESSION_PROTOCOL.md`
3. `PROJECT_MASTER.md`
4. `HANDOVER.md`
5. `PROJECT_TRACKER.md`
6. سایر مستندات مرتبط با وظیفه جاری

## قواعد نگهداری
- هر تغییر واقعی در کد که روی معماری، API، دیتابیس، امنیت، تست یا رفتار کسب‌وکار اثر دارد باید در سند مرتبط منعکس شود.
- وضعیت‌ها فقط پس از بررسی کد و شواهد تست تغییر کنند.
- `HANDOVER.md` باید آخرین وضعیت قابل اتکای پروژه و کار بعدی را نشان دهد.
- فایل‌های این بسته نقطه شروع مستندسازی‌اند؛ بخش‌های «نیازمند بررسی» عمداً خالی مانده‌اند تا اطلاعات حدس زده نشود.
- هرگز Secret، رمز، توکن، کلید خصوصی یا اطلاعات شخصی مشتریان را در مستندات Commit نکنید.
