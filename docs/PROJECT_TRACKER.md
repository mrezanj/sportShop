## قواعد
1. وضعیت `IMPLEMENTED` بدون تست به `TESTED` ارتقا نمی‌یابد.
2. `ACCEPTED` فقط با سناریوی پذیرش مشخص و موفق ثبت می‌شود.
3. اگر Backend آماده و Frontend ناقص است، وضعیت‌ها جدا ثبت شوند.
4. قابلیت خارج از Scope حذف نشود؛ با دلیل `OUT_OF_SCOPE` ثبت شود.
5. برای هر تغییر وضعیت، شواهد (تست، فایل، Commit یا سناریو) درج شود.
